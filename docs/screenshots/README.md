## 截图获取步骤

1. 启动后端：`mvn spring-boot:run`
2. 启动 HBuilderX，打开 `frontend/`，运行到浏览器
3. 在 H5 中依次访问每个页面，用浏览器截图工具（Snipping Tool / Cmd+Shift+4 等）保存为 PNG
4. 将截图放入本目录，按上述命名规范命名
